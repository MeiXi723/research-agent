# 系统规格数字表（评测语料 3）

## 阈值与参数

| 参数 | 数值 |
|---|---|
| 最大代理步数 | 10 |
| 整体超时 | 120 秒 |
| 上下文 token 预算 | 6000 |
| 滑动窗口保留轮次 | 5 |
| LLM 重试次数 | 3 |
| 重试基础延迟 | 1.0 秒 |
| 嵌入维度 | 384 |
| 检索返回条数 TOP_K | 3 |
| 工具结果截断长度 | 500 字符 |

## 多智能体参数

事实核查通过线（PASS_THRESHOLD）为 0.8，即被判定为无依据的句子占比不超过 20% 才算通过。证据单条截断 300 字符，每个子问题最多保留 4 条证据。计划阶段最多拆解 6 个子问题。

## 运行时超时

单次 LLM 请求超时为 60 秒，超时后走既有指数退避重试通道。MCP 工具调用超时默认为 30 秒，由 provider 的硬闸 future.result(timeout) 强制执行。
