# 研究代理系统笔记（评测语料 1）

## 架构

本系统采用 ReAct（Reasoning + Acting）范式驱动单智能体循环。每轮决策流程为：思考 → 选择工具 → 执行 → 观察结果 → 继续或给出最终答案。最大步数默认为 10 步，整体超时阈值为 120 秒。

上下文管理采用滑动窗口加摘要策略：当对话 token 估算超过 6000 时，保留最近 5 轮用户消息，其余历史交给摘要器压缩成两句话以内的概述。

## 记忆

长期记忆分为两层：键值层直接按 key 读取；语义层用嵌入向量召回，检索时返回与查询语义最相关的若干条历史结论。记忆条目包含键名、内容、来源会话和创建时间。

## 工具协议

智能体通过 OpenAI function calling 协议调用工具。每个工具声明名称、描述和参数 JSON Schema。MCP 协议让外部工具服务器以子进程方式接入，工具名采用「服务器名__工具名」的命名空间格式，避免不同服务器的同名工具冲突。
